# 单集制作包模板

## 1. 制作简报

- 集号 / 标题 / 一句话目标
- 平台 / 画幅 / 目标时长 / 受众
- 本集情绪曲线 / 核心冲突 / 结尾钩子
- 本集沿用的硬约束与必要假设

## 2. 连续性快照

- 登场人物当前造型、状态、位置和关系
- 场景布局、时间、天气、光线与关键道具
- 上集承接点、已知信息和待回收伏笔

## 3. 分场剧本

每场包含：场号、内/外景、地点、时间、预计时长、人物、场景目标、动作、台词、转折和出场点。

## 4. 镜头表

| 镜号 | 时长 | 景别/机位/运动 | 画面与表演动作 | 台词/声音 | 生成提示或拍摄重点 | 连续性 |
|---|---:|---|---|---|---|---|

镜号推荐使用 `EP02-S03-SH05`。复杂动作拆成多个镜头，单镜头只保留一个主要视觉意图。

## 5. 生成资产清单

- 人物定妆/参考图
- 场景建立图与方位参考
- 关键道具
- 分镜或首尾帧
- 视频镜头、对白/旁白、音乐、音效、字幕

对每项标明：复用/新建、数量、规格、依赖、命名和验收标准。

## 6. 后期方案

- 镜头顺序、剪辑节奏、转场依据
- 音乐进入/退出点、环境声、重点音效
- 字幕样式与安全区、调色与统一性要求

## 7. 质检与返工

- 剧情、连续性、可生成性、声画、合规检查结果
- 问题镜号、严重度、原因、修正动作、复检结果

## 8. 集末状态更新

- 人物与关系变化
- 场景/道具变化
- 新增事实与已揭示信息
- 未回收伏笔
- 下一集硬约束
- 新增质量经验
