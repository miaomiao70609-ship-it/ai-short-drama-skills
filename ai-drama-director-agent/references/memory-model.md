# 通用项目记忆模型

需要维护多集连续性时，使用以下字段。可用 Markdown、JSON、表格或项目现有格式保存，不强制创建数据库。

## 项目

- 项目名、项目类型、题材、基调、受众、平台、画幅、时长、视觉规则、叙事规则、品牌/教学目标、内容边界。

## 人物

- ID / 姓名 / 别名
- 不可变外貌 DNA：年龄段、脸型、肤色、发型发色、体态、识别特征
- 当前造型：服装、鞋、配饰、妆发、伤势、污渍
- 性格、欲望、恐惧、秘密、说话方式
- 关系、所知信息、当前位置、身体与情绪状态
- 首次出现、最近更新、依据来源

## 场景

- ID / 名称 / 空间类型
- 固定布局、门窗与出入口、关键方位、固定道具
- 时间、天气、主光方向、色温、主色、环境声
- 可变状态及变化原因

## 故事

- 集/场/镜标识
- 事件、原因、结果、参与者、发生时间
- 谁知道 / 谁不知道
- 已兑现信息、未回收伏笔、截止条件

## 质量经验

- 问题类别、失败表现、可能原因
- 使用的模型或制作条件（若已知）
- 修正动作、验证结果、适用范围、禁用方案

## 表现记忆

- 资产版本、发布平台、发布时间和目标
- 标题、封面、开头、时长、行动号召等实验变量
- 曝光、点击、完播、互动、转化等用户实际提供的指标
- 数据窗口、样本限制、结论置信度和下一轮假设

## 更新规则

1. 区分“不可变设定”“当前状态”“暂定假设”。
2. 只把画面中发生、台词明确说明或用户确认的事实写入正式记忆。
3. 记录变化前后状态和依据，避免只保留结论。
4. 冲突时采用最新明确确认版本，并保留冲突提示供用户裁决。
5. 每集结束生成一份增量更新，不重复整份项目圣经。
6. 将预测、目标和实测分栏保存；指标缺失时保留待回填，不得编造。
