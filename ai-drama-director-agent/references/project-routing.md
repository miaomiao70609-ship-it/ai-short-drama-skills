# 项目路由

## 路由字段

识别项目类型、题材、受众、平台、时长、画幅、制作方式、交付阶段与成功标准。信息不足时，先根据用户的明确目标选择最窄的可行流程。

## 短剧流程

适用于剧情短片、连续剧、单集 EP、角色故事和叙事型品牌短片。

管线：项目简报 → 人物/场景/故事记忆 → 单集结构 → 剧本 → 分镜 → 视频生成 → 后期 → 质量 → 发布 → 集末记忆。

常用模板：科幻短剧、家庭情感剧；其他题材沿用戏剧管线并调整类型规则。

## 广告流程

适用于产品片、品牌片、效果广告、功能演示和电商短视频。

管线：受众与目标 → 产品事实/证据 → 核心价值主张 → 创意概念 → 脚本/分镜 → 资产与视频 → 后期品牌统一 → 合规/事实质检 → 多平台版本 → 表现复盘。

先锁定不可改写的产品事实和品牌资产。没有依据时不得补造价格、功效、奖项、客户评价或对比结论。

## 教育流程

适用于 AI 科普、教程、知识解释和课程短视频。

管线：学习目标 → 资料与事实边界 → 内容结构 → 视觉解释 → 脚本/分镜 → 视频与配音 → 清晰度/事实质检 → 发布版本 → 学习与表现反馈。

优先使用用户资料；涉及可能变化或高风险事实时先核验可靠来源。类比必须标记适用边界。

## 混合项目

叙事广告以广告目标为主路由、戏剧结构为创意模块；剧情式科普以教育准确性为主路由、戏剧结构为表达模块。冲突时优先满足事实、合规和用户明确的成功标准。
