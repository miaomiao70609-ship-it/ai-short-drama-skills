# 专业 Skill 路由

| 节点 | Skill | 主要输入 | 主要输出 |
|---|---|---|---|
| 编剧 | `$ai-drama-scriptwriting` | 创意、素材、项目约束、历史记忆 | Script Package、质量报告、下游交接 |
| 人物 | `$ai-drama-character` | 剧本人物功能、角色需求 | Character Bible、身份锚点、表演与连续性规则 |
| 场景 | `$ai-drama-scene` | 剧本场次、角色包、场景需求 | World/Location Bible、空间与光线规则 |
| 分镜 | `$ai-drama-storyboard` | 剧本、人物包、场景包 | Shot List、摄影、表演、衔接方案 |
| 视频 | `$ai-drama-video` | 分镜、参考资产、目标模型 | 逐镜生成卡、首尾帧、运动与负向约束 |
| 后期 | `$ai-drama-editing` | 分镜、生成素材、声音资产 | 时间线、声音、字幕、调色、导出方案 |
| 质检 | `$ai-drama-quality` | 各阶段产物与实际素材 | 分数、问题证据、严重度、返修计划 |
| 发布 | `$ai-drama-publishing` | 通过质检的成片与平台目标 | 平台版本、标题封面、发布与复盘方案 |

## 使用规则

1. 单阶段请求直接使用对应 Skill。
2. 完整项目由总导演按依赖顺序协调交接。
3. 不替专业 Skill 越权决定其核心内容：编剧定义戏剧事实，分镜决定摄影语言，视频决定模型执行方案。
4. 每个交接包包含来源版本、锁定事实、可变字段、风险、待确认项和下游验收标准。
5. 用户明确省略某节点时记录跳过原因，并检查下游是否仍具备足够输入。
